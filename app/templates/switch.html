Change the switch address

For when the switch's management address or NX-API port changed. NXray signs in at the new address with its own account first, and keeps the old address if that does not work. No admin login is needed.

Run setup again

For when NXray's login stopped working: the account's password was changed or the account was removed on the switch, or NXray can no longer read its stored copy. NXray signs in to the switch's NX-API once with the admin login below and gives its account {{ connection.username }} a new random password, or makes it again under the same name if it is gone. The account keeps its permissions: port changes stay on if the switch still has the {{ role_name }} role. The admin password is used for this only and never stored.

To use another account name instead, press Forget this switch and set it up again with the new name.

Afterwards NXray runs copy running-config startup-config, which also saves any other unsaved changes on the switch.

{% else %}

Set up the switch

NXray signs in to the switch's NX-API once with an admin login, creates its own read-only account (role network-operator) with a long random password, and from then on uses only that account. The admin password is used for this setup only and is never stored.

Each NXray install needs its own name, for example nxray on the production machine and nxray-dev on a test machine. Setup stops if the name already exists on the switch.

When the account is made, NXray runs copy running-config startup-config so the account survives a restart of the switch. That also saves any other changes on the switch that have not been saved yet.
